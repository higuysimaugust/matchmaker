# Matchmaker/Ranked Joiner

Alright, ranked is here, so is august.matchmaker!
(Early version, still has debug and probably broken :/ pls report bugs and feedback and all)

Ranked servers aren't visible in the server browser but everyone still has permissions to join them... so I made an ez way to join the servers!

## How to use
- Pick the server number (0: `Matchmaking`, 1: `Matchmaking_1`, etc.)
- Press Join

## Download
- Press Install!
